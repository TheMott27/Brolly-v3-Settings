# Brolly v3.1.0 Public Release

This repository contains the public settings-page baseline coordinated with the first public Brolly v3 watchface release. It is published separately from the existing Brolly 2.x settings repository.

| Item | Value |
|---|---|
| Coordinated public version | `3.1.0` |
| Source testing version | `3.0.0` |
| Public release branch | `Brolly-v3.1.0` |
| Public release target | `main` in `TheMott27/Brolly-v3-Settings` |

The private testing repository remains the default destination for all future settings-page development. A public release occurs only after the explicit `BUILD MAIN` instruction.
